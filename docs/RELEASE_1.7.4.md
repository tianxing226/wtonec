# Wtonec 1.7.4 更新说明

Wtonec 让你在微信、QQ、小红书、抖音中使用文字转语音、语音包、语音播报、克隆音色和表情包。

**上百款音色可选，所有音色和功能均免费使用，无需充值。**

## 更新一览

1. 优化 API Key 保存，修复反复要求保存的问题。
2. 优化各软件面板之间的数据同步，使用更流畅。
3. 优化部分权限处理。
4. 修复液态玻璃出现黑色子块、内容看不清的问题。
5. 修复开启 VPN 或代理时可能出现的语音发送失败。
6. 修复语音发送成功后的回执提示。
7. 新增小红书私聊、群聊的语音发送和表情包功能，适配 **9.49.1**。
8. 新增抖音私聊、群聊的语音发送和表情包功能，适配 **40.7.0**。
9. 小红书、抖音的其他版本请自行测试。
10. 更换软件包名为 `dev.wtonec.final`，安装后请重新启用模块。
11. 所有音色和功能均免费使用，无需充值。

## 安装提醒

**抖音、小红书必须先在 Wtonec「设置」页面开启对应应用的悬浮窗入口，才能在聊天页点击悬浮球使用。**

- Android 9 及以上，需要已配置的 LSPosed/Xposed 环境。
- 一个通用 APK，包含 ARM64 与 ARMv7；版本 **1.7.4 / 703**，约 **14 MiB**。
- 新包名与旧版不同，会作为新应用安装；旧版数据不会自动迁移。先导出需要保留的语音包，再启用新版、停用旧版模块，并重新勾选所需应用作用域。
- 完全结束并重启对应应用。在线音色按应用提示配置自己的 API Key，系统 TTS 和本地语音包无需 Key。
