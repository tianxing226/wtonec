# Wtonec 使用说明

Wtonec 为微信、QQ、小红书和抖音提供文字转语音、语音包、语音播报、音色克隆和表情包功能。

支持数百款音色、面板数据共享和液态玻璃主题。**所有音色和功能均免费，无需充值。** 在线音色按界面提示配置自己的 API Key。

当前版本：**1.7.5（707）**；包名：`dev.wtonec.final`。需要 Android 9 及以上和可用的 LSPosed/Xposed 环境，支持 ARM64 / ARMv7。
