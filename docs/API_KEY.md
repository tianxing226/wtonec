# API Key 配置

**所有音色和功能均免费，无需充值。** 部分在线音色需要保存自己的 API Key，用于连接对应在线服务。

## 哪些功能需要

| 功能 | Tiax API Key |
|---|---|
| Fish Audio、轻颜、ElevenLabs 在线音色与克隆 | 按界面提示配置 |
| Android 系统 TTS | 不需要 |
| 本地语音包 | 不需要 |
| 公开在线语音样例 | 不需要 |

## 获取并保存

1. 打开 [Tiax 官网](https://www.tiax.pw/)，登录自己的账号。
2. 在 [用户中心](https://www.tiax.pw/user/) 的 API 密钥管理中获取 Key。
3. 打开 Wtonec 或聊天中的 Wtonec 面板，进入“设置”。
4. 填写自己的 `Tiax API Key` 并保存，再返回音色页面使用。

1.7.4 优化了 Key 保存和各应用面板的数据同步，正常使用无需反复保存。

## 无法使用时

- 提示未配置：确认已经保存，关闭并重新打开目标应用。
- 在线生成失败：检查网络、Key 是否有效、音色是否可用和服务状态。
- 仅某个应用没有同步：先打开 Wtonec 查看配置，再重启该应用。
- 系统 TTS 没声音：检查系统语音引擎和语言数据，它不读取 Tiax Key。

Key 属于个人凭据，请勿放进公开截图、日志或问题反馈。不要使用他人公开分享的 Key。

如使用安全页的第三方 AI 功能，其接口地址、Key 和模型需要单独配置，与语音 Key 分开。联网内容见 [隐私说明](PRIVACY.md)。
