# 功能使用

Wtonec 支持微信、QQ、小红书、抖音的语音与表情包功能。**所有音色和功能均免费，无需充值。**

## 打开面板

进入私聊或群聊，点击 Wtonec 悬浮球。微信还可切换到语音输入后长按语音按钮。生成或发送前，先确认当前聊天对象。

## 文字转语音

1. 选择音色来源，搜索或挑选喜欢的音色。
2. 输入想说的文字，按需要调整语速等选项。
3. 生成并试听，满意后保存或发送。

提供数百款音色，可使用 Fish Audio、轻颜、ElevenLabs 等在线来源，也可选择 Android 系统 TTS。在线音色按界面提示配置自己的 [API Key](API_KEY.md)，音色列表与来源状态以应用内显示为准。

## 克隆音色

打开克隆功能，按页面提示选择音频或填写已有音色 ID，保存后即可选择该音色生成语音。请使用自己或已获授权的声音；在线克隆会上传所选音频。

## 语音包

- 导入本地音频，或在在线语音包中搜索素材。
- 支持试听、保存、分类、重命名、导出和发送。
- 常用语音可以重复使用；多个应用的面板可共享配置和语音包数据。
- 在线来源暂时不可用时，可先使用本地语音包或其他来源。

## 语音播报

在面板中打开语音播报，按页面选项选择需要的播报方式和音色。先试听并调整音量，再按需要启用。

## 表情包

在表情包页面选择或管理素材，确认当前聊天后发送。小红书和抖音新增支持私聊、群聊中的语音与表情包功能，适配版本见 [应用说明](DUAL_HOST.md)。

## 主题与悬浮球

可调整悬浮球和面板外观，支持液态玻璃等主题。1.7.4 修复了液态玻璃黑色子块影响阅读的问题；如果背景过于复杂，可切换其他主题。
