# 隐私与联网说明

Wtonec 包含本地功能和在线功能。使用在线音色、克隆、素材下载或发送消息时，会连接相应服务。

## 哪些内容会联网

| 操作 | 相关数据与接收方 |
|---|---|
| 在线文字转语音 | 输入文字、音色参数和 API Key 会发送给所选接口服务；Tiax 接口可转发至对应音色服务 |
| 在线克隆音色 | 所选音频与克隆参数会上传到对应服务 |
| 在线语音包、表情包或音色目录 | 请求相应来源站点、目录或媒体地址，搜索时可能发送关键词 |
| 在聊天中发送内容 | 通过微信、QQ、小红书或抖音的消息服务发送给当前聊天 |

第三方服务的数据处理和保留方式以其说明为准。不要在输入内容、克隆音频或反馈材料中放入无关的隐私信息。

## 本地内容与凭据

- 本地语音包的音频处理在设备上完成；发送到聊天时仍会使用对应应用的网络服务。
- Android 系统 TTS 不读取 Tiax API Key，但系统语音引擎是否联网取决于所选引擎。
- API Key 保存在设备配置中并采用加密保护；请勿公开分享或截入演示图片。
- 应用会保存设置、语音包、适配缓存和诊断日志，多个应用的面板可共享相关配置和语音数据。
- 日志、截图和导出的报告可能包含设备或使用信息，分享前需要自行检查。

## 分享与删除

公开截图或日志前，遮盖 API Key、Token、账号、联系人、群号、聊天内容和设备标识。只上传排查问题必需的内容。

清除数据或卸载前，先 [导出重要语音](STORAGE.md)。清理本机数据不会自动删除已经发送给聊天对象或在线服务的内容。
