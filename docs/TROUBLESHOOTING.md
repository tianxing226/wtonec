# 常见问题

**抖音、小红书必须先在 Wtonec「设置」页面开启对应应用的悬浮窗入口，才能在聊天页点击悬浮球使用。**

## 没有面板或模块未生效

1. 确认已安装 1.7.6 / 708，并在模块管理器中启用包名为 `dev.wtonec.final` 的新版。
2. 勾选目标应用的作用域；如仍保留更早不同包名的旧模块，请停用旧模块。
3. 完全关闭并重新打开目标应用，进入私聊或群聊。
4. 检查 Wtonec 悬浮球是否开启；微信可切换到语音输入后长按语音按钮。

小红书适配 **9.49.1、9.50.0**，抖音适配 **40.7.0**；其他版本请自行测试。各应用的标准包名见 [适配说明](DUAL_HOST.md)。

## 反复出现适配匹配页面

保持目标应用在前台，等待匹配完成，再完全关闭并重启。应用升级、降级后重新匹配属于正常情况；仍失败时请记录应用版本和提示内容。

## 提示 Key 未保存或在线音色失败

1. 在设置中确认已保存自己的 [API Key](API_KEY.md)。
2. 检查网络、Key 有效性、音色和在线服务状态。
3. 重新打开 Wtonec 和目标应用后再试。

1.7.4 已优化 Key 保存，无需每次使用都重新填写。所有音色和功能均免费，无需充值。

## 语音没有发送成功

- 确认当前聊天对象，先试听，等待发送结果，避免连续点击。
- 检查网络及对应应用是否能正常收发消息。
- 1.7.4 修复了 VPN / 代理环境下的语音发送问题及发送成功回执；仍有异常时，可切换网络后重试并记录代理是否开启。
- 查看聊天中是否出现语音、是否能播放，并确认对方是否收到。

反馈时附上应用版本、私聊或群聊、操作步骤和提示内容。界面截图只能展示外观，不能单独证明语音已送达。

## 语音包导入、保存或共享失败

确认音频本身可以播放、设备空间充足，并使用系统文件选择器重新导入。不同应用数据未同步时，先打开 Wtonec，再重启对应应用；重要语音先导出备份。

## 系统 TTS 没声音

打开 Android 系统语音设置，确认已安装语音引擎和对应语言，完成初始化后重新打开面板。

## 液态玻璃看不清

更新到 1.7.6 并重启目标应用。如背景影响阅读，可更换主题。

## 反馈需要提供什么

- Wtonec、Android、模块管理器及目标应用版本。
- 出错功能、操作步骤、提示内容和大致时间。
- 必要的截图或日志，发送问题补充对方是否收到。

提交前遮盖 API Key、账号、联系人、聊天内容及其他个人信息。
