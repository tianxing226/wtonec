# 使用须知

Wtonec 是独立维护的 Android 语音工具，为微信、QQ、小红书和抖音提供相关功能，与这些平台及音色服务提供方不存在隶属或官方背书关系。

**所有音色和功能均免费，无需充值。** 在线功能需要可用网络，部分在线音色需要自己的 API Key；可用性以应用内和服务状态为准。

- 使用自己或已获授权的声音、音频和表情素材，遵守所在地法律及相关平台规则。
- 不要冒充他人、侵犯隐私、欺诈、骚扰或传播侵权内容。
- 发送前确认聊天对象和内容；妥善保管自己的 API Key。
- Android、模块管理器或聊天应用更新可能影响兼容性，更新前先备份重要语音。
- 清除数据或卸载可能删除设置、语音包和缓存；联网和数据处理说明见 [隐私说明](PRIVACY.md)。

反馈问题时请移除 Key、账号、联系人、聊天内容和其他个人信息。公开仓库中的历史独立样例不代表完整模块源码。
