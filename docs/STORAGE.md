# 备份与清理

Wtonec 会在设备上保存设置、语音包和使用缓存。多个应用的面板可共享部分数据，各应用也会保留自己的文件与缓存。

## 备份重要内容

1. 在“语音包”中将重要语音导出为 MP3，保存到自己选定的位置。
2. 记录自定义音色名称、音色 ID 和需要保留的设置。
3. 更新、卸载或清除数据前，先确认导出的音频可以播放。

1.7.4 已更换包名为 `dev.wtonec.final`。不要假设旧版数据会自动迁移；先在旧版导出，再到新版导入。

## 导入与导出

- **导入：** 打开语音包页面，通过系统文件选择器选择音频。
- **导出：** 在语音条目中选择导出，再选择保存位置。
- **删除：** 使用应用内的删除功能，避免手工删除文件后留下失效条目。

## 文件在哪里

相关应用的数据一般保存在 Android 的应用目录中。Wtonec 使用的常见目录形式为：

```text
/storage/emulated/0/Android/data/<应用包名>/Wtonec/
/storage/emulated/0/Android/data/<应用包名>/cache/Wtonec/
```

实际目录以应用内显示和设备系统为准。Android 11 及以上可能限制普通文件管理器访问 `Android/data`，优先使用 Wtonec 内置导入、导出和清理功能。

## 清理时注意

- 等待生成、下载和发送结束后再清理缓存。
- 清理适配缓存后，下次使用可能需要重新匹配。
- 清除应用数据或卸载可能删除设置和语音包，先备份重要内容。
- 日志仅在排查问题时保留；分享前遮盖 Key、账号和聊天信息。
