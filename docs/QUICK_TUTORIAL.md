# Wtonec 简单使用教程

**把文字变成语音，在微信、QQ、小红书、抖音聊天中使用，还能发送语音包和表情包。** 所有音色和功能均免费，无需充值。

## ① 安装并启用

1. 准备 Android 9 及以上设备，以及已配置好的 LSPosed/Xposed。
2. 打开 [GitHub 下载页](https://github.com/tianxing226/wtonec/releases/latest) 或 [Xposed 仓库下载页](https://github.com/Xposed-Modules-Repo/dev.wtonec/releases/latest)，展开 **Assets（资源）**，下载后缀为 **`.apk`** 的安装包并安装。
3. 打开 LSPosed/Xposed 的模块管理页面，启用 **Wtonec**，勾选你要使用的微信、QQ、小红书或抖音。
4. 完全关闭并重新打开这些应用；如出现匹配提示，按提示完成，再重启对应应用。

从旧版升级：1.7.4 已更换包名，请先导出重要语音包，再启用新版、停用旧版模块，并重新勾选应用。旧版数据不会自动迁移。

## ② 打开聊天面板

**使用抖音、小红书前，必须先打开 Wtonec →「设置」→ 开启对应应用的悬浮窗入口。**

| 使用的应用 | 怎么打开 Wtonec 面板 |
|---|---|
| 微信 | 进入私聊或群聊，点击已开启的悬浮球；也可切换到语音输入后长按语音按钮 |
| QQ | 进入私聊或群聊，点击已开启的 Wtonec 悬浮球 |
| 小红书 / 抖音 | 先在 Wtonec 设置中开启对应悬浮窗，再进入聊天页点击悬浮球 |

小红书适配 **9.49.1**，抖音适配 **40.7.0**；其他版本请自行测试。

## ③ 发送第一条文字语音

1. 在面板中选择喜欢的音色，输入一句话，例如：**“你好，今天也要开心！”**
2. 如果在线音色提示需要 API Key，到 Wtonec「设置」填写并保存自己的 Key。[查看 Key 配置方法](API_KEY.md)
3. 点击 **试听**，确认声音和内容。
4. 确认当前聊天对象，再点击 **生成并发送**；也可以先保存，稍后发送。

想先试用：选择 **系统 TTS**，无需 API Key；如果没有声音，先在系统设置中安装或启用语音引擎及中文语音数据。

## 其他功能怎么用

| 功能 | 简单操作 |
|---|---|
| 语音包 | 打开「语音包」→ 导入本地音频或选择在线素材 → 试听 → 发送 |
| 克隆音色 | 打开「克隆」→ 按页面提示选择音频或填写已有音色 ID → 保存 → 用该音色生成语音 |
| 表情包 | 打开表情包页面 → 选择喜欢的表情 → 确认当前聊天后发送 |
| 语音播报 | 打开语音播报设置 → 按提示开启所需权限 → 选择播报方式和音色 → 启用 |
| 主题 / 悬浮球 | 打开 Wtonec「设置」→ 调整面板外观、悬浮窗或图标 |

## 遇到问题先看这里

- **找不到悬浮球：**检查 Wtonec 是否已启用、是否勾选当前应用；抖音和小红书还要开启对应悬浮窗，然后完全关闭并重启该应用。
- **在线语音生成失败：**检查网络、Key 是否已保存，以及当前音色是否可用，也可以换个音色试试。
- **系统 TTS 没声音：**检查系统语音引擎、中文语音数据和媒体音量。
- **应用更新后不能用：**按提示重新匹配；小红书和抖音可先核对上面的适配版本。
