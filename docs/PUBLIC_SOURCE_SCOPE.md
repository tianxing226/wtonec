# 公开仓库内容范围

这两个仓库用于 Wtonec 的安装包发布、使用说明和演示展示：

- [`tianxing226/wtonec`](https://github.com/tianxing226/wtonec)：项目介绍、官网和下载。
- [`Xposed-Modules-Repo/dev.wtonec`](https://github.com/Xposed-Modules-Repo/dev.wtonec)：Xposed 模块目录展示和下载。

## 本次更新公开什么

- GitHub Releases 中的 APK 安装包。
- 简明的功能、安装、适配、更新和隐私说明。
- 已检查并去除敏感信息的演示图片。

本次更新不上传私有源码、API Key、Token、私钥、密钥库、签名配置、个人数据、运行日志或内部报告。APK 作为 Release 附件发布，不放入 Git 文件历史。

## 历史文件

仓库中已有少量独立接口与模型样例，以及公开素材目录。这些是历史公开内容，不是本次新增上传的源码，也不构成完整模块或可安装工程。

历史发布说明保留对应版本的信息，当前安装方式、包名和功能以 [最新使用说明](README.md) 为准。
