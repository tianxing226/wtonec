1.7.4 更新一览

小红书、抖音加入，常用体验继续改进。

  1. 优化 API Key 保存，修复反复要求保存的问题。
  2. 优化各软件面板的数据同步，使用更流畅。
  3. 优化部分权限处理。
  4. 修复液态玻璃出现黑色子块、内容看不清的问题。
  5. 修复开启 VPN 或代理时可能出现的语音发送失败。
  6. 修复语音发送成功后的回执提示。
  7. 新增小红书私聊、群聊语音发送和表情包，适配 9.49.1。
  8. 新增抖音私聊、群聊语音发送和表情包，适配 40.7.0。
  9. 小红书、抖音的其他版本请自行测试。
  10. 更换软件包名为 dev.wtonec.final，安装后请重新启用模块。
  11. 所有音色和功能均免费使用，无需充值。

安装后，几步开始使用

  1. 下载并安装 APK，在 LSPosed/Xposed 中启用 Wtonec。
  2. 按需勾选微信、QQ、小红书、抖音，完全结束并重启对应应用。
  3. 按提示完成初始化，在聊天页打开悬浮球面板。
  4. 在线音色按提示配置自己的 API Key；系统 TTS 和本地语音包无需 Key。

从旧版升级

本版包名变更，会作为新应用安装。请先导出需要保留的语音包，再启用新版、停用旧版模块，并重新勾选作用域。

旧版数据不会自动迁移。小红书 9.49.1、抖音 40.7.0 之外的版本请自行测试。
